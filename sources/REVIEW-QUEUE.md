## B. 출처 간 충돌·불확실 항목

- [ ] **B1. 나타(Natah) 해금 조건 서술 불일치** — 위키 인포박스는 "천왕성 정크션",
  워크스루는 "아크윙 완료 후 시작 가능", 해왕성 정크션의 힌트는 "천왕성 미션에서
  낯선 드론 조우"라고 각각 다르게 서술한다(구버전 잔재로 추정). 데이터에는
  선행조건으로 천왕성 정크션 + 아크윙 둘 다 기록했다. 실게임 확인 필요.
  - *2026-08-04 국내 교차 검증 보강*: 오디스 갤러리 나타 가이드(2024-01)에 따르면
    세 서술은 상충이 아니다 — 천왕성 정크션·아크윙이 선행 조건이고, 천왕성 노드에서
    오큘리스트 드론을 조우하면 퀘스트가 트리거되며, 첫 임무의 드론 스캔은 지구
    가이아에서 진행된다. 현행 데이터(둘 다 선행조건)는 그대로 유효. 근거:
    `knowledge/notes/quest-natah.md`
- [ ] **B2. 정크션 개요 페이지 vs 개별 페이지 불일치** — 개요 페이지의 리워크
  공지에는 금성 정크션 과제가 "Vor's Prize 완료"로 남아 있으나, 개별 페이지는
  "The Teacher 완료"(Update 40 이후)다. 개별 페이지를 채택했다. 실게임 확인 권장.
- [ ] **B3. 메인 퀘스트 권장 순서: 하트 오브 데이모스 ↔ 아크윙** — 위키의
  previous/next 체인은 원스 어웨이크 → 하트 오브 데이모스 → 아크윙 순이지만, 둘 다
  화성 정크션에서 동시에 해금된다. 데이터에는 둘 다 선행조건을 화성 정크션으로
  두어 병렬로 표현했다. 뉴비 권장 순서를 강제할지 운영자 판단 필요.

- [ ] **B4. 퀘스트 한글 표기: 음차 → 한국어 클라이언트 정식 명칭** — 국내 교차
  검증(2026-08-04, 오디스 갤러리 가이드)으로 한국어 클라이언트 정식 번역명이
  확인됐다. 현행 데이터의 음차 표기와 다르다: 보의 전리품→**보어의 전리품**,
  더 티처→**스승**, 원스 어웨이크→**각성의 순간**, 하트 오브 데이모스→**데이모스의
  심장**, 세컨드 드림→**두 번째 꿈**. 또한 클라이언트는 Junction을 '정크션'이
  아니라 **교차점**으로 표기한다. 뉴비가 게임 화면과 대조하기 쉬우려면 클라이언트
  표기를 따르는 것을 권장. 승인 시 `roadmap-nodes.json` 제목·본문 일괄 수정.
  근거: `knowledge/notes/quest-names-ko.md`
- [ ] **B5. caution 표현 보정 2건(경미)** — (1) 아크윙: "발굴 보상이 무작위라 여러 번
