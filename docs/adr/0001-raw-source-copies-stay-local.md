# 0001. 원천 자료 원문 사본은 로컬 전용(gitignore)으로만 보관한다

날짜: 2026-08-04
상태: 승인됨

## 맥락

콘텐츠 소싱 파이프라인은 커뮤니티 자료(오디스 코덱스 시트, 갤러리 가이드 글)와
공식 위키에서 사실을 추출한다. 에이전트의 집필·검증 품질을 높이려면 원문을
반복 참조할 수 있는 지식 베이스가 필요한데, 원문 사본을 저장소에 커밋하면:

- 커뮤니티 글 작성자의 저작권을 침해한다 (갤러리 글은 CC가 아니다)
- 시트 파일 커밋은 "특정 출처 DB 통째 이관 금지" 원칙(스펙 #1)에 정면으로 걸린다
- 이 저장소는 포트폴리오로 공개 심사되므로 "내부용"이라는 방어가 성립하지 않는다

반면 사본을 아예 만들지 않으면 매 세션 원문을 다시 긁어야 하고, 원 글이
지워지면 근거가 소실된다.

## 결정

원문 사본(`knowledge/`)과 원천 파일(`sources/ordis-codex-v3.5/`)은 로컬
디스크에만 두고 `.gitignore`로 저장소에서 제외한다. 조사·학습을 위한 사적
복제로만 사용한다.

- 출처 등록부에는 원본의 URL·수집일만 등록한다 (파일 아님)
- 지식 베이스에서 파생돼 서비스 데이터(`src/data/`)로 나가는 문장은 반드시
  자체 재서술을 거치고 출처 크레딧을 단다 — 원문 문장이 그대로 흘러가면 안 된다
- 지식 베이스 구축 계획과 진행 상태(`knowledge/PLAN.md`)도 로컬에 남는다.
  다른 머신에서 이어가려면 원천 파일과 함께 수동으로 옮긴다

## 결과

- 저작권·DB권 리스크 없이 원문 반복 참조가 가능해진다
- 지식 베이스는 클론만으로 복원되지 않는다 — 머신 이동 시 수동 복사 필요
- 실수 커밋을 막는 방어선이 `.gitignore` 하나이므로, 새 원천 디렉터리를 만들
  때는 반드시 gitignore 등록을 먼저 한다
